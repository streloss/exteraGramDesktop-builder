# exteraGram Desktop (Windows x64)

Десктопная сборка **exteraGram Desktop** на базе C++20 / Qt6 и форка Telegram Desktop (AyuGram) с автоматической облачной компиляцией в **GitHub Actions**.

---

## ✨ Возможности сборки

* **Ghost Mode (Режим невидимки)**:
  * Не отправлять статус «онлайн» в сеть.
  * Скрытие статуса набора текста («печатает...»).
  * Чтение сообщений без пометки о прочтении (галочки остаются серыми).
  * Скрытый просмотр историй (Stories).
* **Anti-Delete & Anti-Edit**:
  * Сохранение удалённых сообщений собеседников в локальную базу данных SQLite.
  * Просмотр истории изменений отредактированных сообщений.
* **Брендинг exteraGram**:
  * Кастомная иконка в стиле Material You.
  * Изменённое имя приложения и оконных процессов.
  * Отключение встроенной рекламы и спонсорских постов Telegram.

## 🚀 Запуск сборки в 1 клик (без Git и компиляторов)

Для запуска сборки на вашем компьютере не нужны компиляторы (Visual Studio) и даже утилита `git`. Достаточно стандартного Python.

### Шаг 1. Получение токена GitHub (1 минута)
1. Откройте страницу создания токена:  
   👉 **[Создать Personal Access Token на GitHub](https://github.com/settings/tokens/new?scopes=repo,workflow)**
2. В поле **Note** укажите любое имя (например, `extera-builder`).
3. Убедитесь, что отмечены галочки:
   * `repo` (полный доступ к репозиториям)
   * `workflow` (доступ к запуску Actions)
4. Нажмите внизу **Generate token** и скопируйте полученный ключ (`ghp_...`).

### Шаг 2. Запуск развёртывания
В терминале перейдите в папку проекта и выполните:

```powershell
python deploy_to_github.py
```

Скрипт автоматически:
1. Авторизуется на вашем GitHub.
2. Создаст репозиторий `exteraGramDesktop-builder`.
3. Загрузит воркфлоу сборки `.github/workflows/build.yml` и скрипты патчинга.
4. Запустит сборку Windows x64 в облаке на серверах GitHub.

## 📥 Где скачать готовый `.exe`?

После завершения компиляции в GitHub Actions (обычно первая сборка занимает около 30–50 минут, последующие за счёт кэша — 5–10 минут):
1. Перейдите во вкладку **Releases** в вашем созданном репозитории:
   `https://github.com/<ваш_логин>/exteraGramDesktop-builder/releases`
2. Скачайте архив **`exteraGram-Desktop-x64.zip`**.
3. Распакуйте архив в любую папку и запустите **`exteraGram.exe`**!

## 🛠 Структура файлов репозитория

* `.github/workflows/build.yml` — сценарий сборщика для Windows-2022 раннера (MSVC 2022, Ninja, CMake, Qt6).
* `.github/scripts/patch_branding.py` — автоматический скрипт подмены названия и ресурсов Telegram на exteraGram.
* `resources/` — иконки `icon.ico` и `icon.png` высокого разрешения.
* `deploy_to_github.py` — утилита развёртывания на GitHub через официальный REST API.
